# Downloading the public SenNet CosMx data

## Data source

The CosMx validation data were generated by the SenNet consortium and are available through the following SenNet collection:

- SenNet collection: https://data.sennetconsortium.org/collection?uuid=f198ccd6465f4f19d9729d2e0071b84c

The collection page contains the dataset records and DOI information for the experiments used in this analysis. The experiment identifiers required by the preprocessing script are also listed in `CosMx Data.xlsx`.

## Files required

Each young–old pair is represented by two SenNet dataset records, but the raw CosMx count and metadata files are duplicated between the paired records. Therefore, only **one copy of the raw files is required per pair**.

For each pair, download the following two files from either corresponding dataset record:

- `*exprMat_file.csv`
- `*metadata_file.csv`

## Download procedure

1. Open the SenNet collection page above.
2. Find one of the dataset IDs listed for the desired pair.
3. Open the corresponding dataset page.
4. Scroll to **Globus Access**.
5. Select the linked entry labeled in the form `CosMx Transcriptomics (SNT###.XXXX.###)`.
6. In the Globus File Manager, open the `raw` directory.
7. Download the files ending in `exprMat_file.csv` and `metadata_file.csv`.
8. Repeat for each of the four pairs.

For example, the dataset page below contains the Globus link for `SNT963.RCDL.749`:

- https://data.sennetconsortium.org/dataset?uuid=f7007efa07b85d19eb67001b9081201d

## Expected local organization

Place one downloaded raw-data directory per pair under a common input directory. The directory may be named with either dataset ID belonging to that pair. The preprocessing script searches recursively within each directory, so the CSV files may remain inside a nested `raw/` folder.

```text
data/raw/cosmx/
├── SNT963.RCDL.749/
│   └── raw/
│       ├── 07_Schafer_F3_239_YF03_exprMat_file.csv
│       └── 07_Schafer_F3_239_YF03_metadata_file.csv
├── SNT362.WGWV.528/
│   └── raw/
│       ├── ..._exprMat_file.csv
│       └── ..._metadata_file.csv
├── SNT667.PZVJ.386/
│   └── raw/
│       ├── ..._exprMat_file.csv
│       └── ..._metadata_file.csv
└── SNT685.LPVX.778/
    └── raw/
        ├── ..._exprMat_file.csv
        └── ..._metadata_file.csv
```

The exact filename prefix differs across experiments. The preprocessing script identifies files by the required suffixes rather than by the prefix.

## Run metadata

`CosMx Data.xlsx` defines, for every dataset pair:

- the two SenNet dataset IDs;
- the pair number;
- age in months;
- anatomical plane;
- the inclusive FOV range associated with each age and plane.

Although only one raw count/metadata file pair is downloaded per young–old pair, the files contain FOVs from both ages. The preprocessing script uses the FOV ranges in `CosMx Data.xlsx` to assign each cell its age, anatomical plane, and pair metadata.

## Important notes

- Do not rename the `exprMat_file.csv` or `metadata_file.csv` suffixes.
- Do not download both dataset records for a pair unless you want a redundant copy.
- SenNet data access is managed through Globus. Contact SenNet support with the dataset ID if a file cannot be accessed.
